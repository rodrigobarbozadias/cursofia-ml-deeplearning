Machine Learning and Deep Learning projects from my FIA Business School postgraduate program (2024-2025). Includes classification, regression, clustering, deep learning, and a capstone customer segmentation project

# 🎓 Projetos de Machine Learning e Deep Learning - FIA

Repositório contendo os projetos desenvolvidos durante o curso de Machine Learning e Deep Learning da FIA.

## 📚 Estrutura do Repositório

### 📂 01-python-fundamentos
Fundamentos de Python: operadores, estruturas de dados (listas, tuplas, dicionários), funções e Pandas.

### 📂 02-introducao-ml
Introdução ao Machine Learning:
- Análise Exploratória de Dados (EDA)
- Preparação de dados (ABT - Analytical Base Table)
- Bibliotecas: scikit-learn, ydata-profiling

### 📂 03-classificacao
Técnicas de Classificação:
- Treinamento e avaliação de modelos
- Feature Engineering
- Pipelines e Cross-Validation
- Árvores de Decisão
- Ensembles e Boosting (Random Forest, XGBoost, LightGBM)
- Otimização de hiperparâmetros
- Feature Selection

### 📂 04-regressao
Técnicas de Regressão:
- Regressão Linear
- Métricas de avaliação (MAE, MSE, RMSE, R²)
- Gradient Descent (SGD)
- Modelos de regressão avançados

### 📂 05-clusterizacao
Aprendizagem Não Supervisionada:
- K-Means
- DBSCAN
- Hierárquico
- Análise e interpretação de clusters

### 📂 06-automl
AutoML com PyCaret:
- Automatização de workflows de ML
- Comparação automática de modelos
- Otimização automatizada

### 📂 07-mlops
MLOps e Deploy:
- Pipeline de dados
- Treinamento de modelos
- Predição e deploy

### 📂 08-deep-learning
Deep Learning:
- Redes Neurais
- CNN para classificação de imagens (Fashion MNIST)
- NLP e processamento de texto
- Classificação binária

### 📂 09-projetos-finais
Projetos de conclusão e trabalhos finais integrando os conceitos aprendidos.

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Pandas** - Manipulação de dados
- **NumPy** - Computação numérica
- **Scikit-learn** - Machine Learning
- **TensorFlow/Keras** - Deep Learning
- **PyCaret** - AutoML
- **XGBoost, LightGBM** - Boosting
- **Matplotlib, Seaborn** - Visualização

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/rodrigobarbozadias/cursofia-ml-deeplearning.git
```

2. Abra os notebooks no Google Colab ou Jupyter Notebook

3. Instale as dependências necessárias (cada notebook indica as bibliotecas utilizadas)

## 📊 Principais Projetos

- **iFood Campaign Response**: Análise e modelagem de resposta a campanhas de marketing
- **Fashion MNIST**: Classificação de imagens usando Deep Learning
- **Spam Detection**: Classificação binária de mensagens spam
- **Customer Clustering**: Segmentação de clientes usando técnicas de clusterização
